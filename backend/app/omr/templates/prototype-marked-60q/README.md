# prototype-marked-60q (version 1)

A **project-owned prototype** answer sheet. It is not any institute's real
sheet, and no upstream or community sample artwork is used: the marker and
the sheet picture are generated by `backend/app/omr/sheet_design.py`.

- **Roll number:** 6 numeric digits (one column per digit, rows 0-9).
- **Questions:** 60, four options (A-D), two columns of 30.
- **Alignment:** four corner markers (`omr_marker.png`). OMRChecker finds
  them, straightens the area between their centres, and reads the bubbles
  there, so photographs that are rotated, tilted or off-centre still work
  within limits (see the project report for what was measured).

Geometry (design scale, pixels). The page is 1100 x 1600, measured from the
centre of the top-left marker; markers are centred 60 px inside the sheet
edge, so the whole sheet is 1220 x 1720. Bubbles are 30 x 30.

| Block | Origin (x, y) | Between options | Between rows |
|---|---|---|---|
| Roll (6 columns) | 100, 70 | 36 (digits, down) | 50 (columns, across) |
| Questions 1-30 | 100, 470 | 50 | 36 |
| Questions 31-60 | 600, 470 | 50 | 36 |

Regenerate the marker or a printable blank sheet:

    python scripts/make_prototype_sheet.py --out prototype_sheet.png

Changing any number above is a new template version: edit `template.json`
and `manifest.json` together and bump `version` (the manifest is checked
against the layout whenever the template is loaded).
